# Signal Automated Key Verification Protocol

Signal has introduced automated cryptographic key verification, removing the requirement for users to manually compare safety numbers out-of-band for routine contact changes.

## How it works

The protocol leverages transparency logs and auditable key directories, providing end-to-end cryptographic verification directly within the client application.

## Key facts

- Automated verification is supported across modern desktop and mobile Signal clients.
- Verification status updates dynamically when key changes are observed.
- Eliminates common user friction in establishing verified channels.
